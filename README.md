# Kan ik straks nog doorstromen of mijn hypotheek verlengen?

Onafhankelijke gesprekshulp over hypotheekregels nu en straks, in Nederland en Europa.

Live: https://jeroen-o.github.io/Kan-ik-straks-nog-doorstromen-of-mijn-hypotheek-verlengen-/

| Bestand | Inhoud |
| --- | --- |
| `index.html` | Gesprekshulp: eigen situatie in drie scenario's (mild, strakker, streng) met printbare gespreksagenda |
| `regels.html` | Hypotheekregels nu en straks: bankbeleid, renteaftrek, Europa-vergelijking, feitencheck |
| `scenario-2035.html` | Toekomstscenario met zekerheidslabels, stressscenario 2030–2035, rol van de ECB via kapitaal |
| `europa.html` | Europese beleidslijnen en wat andere landen al doen |
| `verhuisscenario.html` | Rekentool: van aflossingsvrij naar annuïtair bij verhuizing, tien scenario's |
| `rekenhulpen.html` | Vier rekenhulpen van Hypotheekbond, geladen na een klik |

Elke pagina is één zelfstandig HTML-bestand (CSS en JavaScript inline), zonder build-stap, cookies of opslag in de
browser. Alleen de rekenhulpen van Hypotheekbond laden na een klik extern. Printen gaat via `window.open`, zodat het ook werkt als de pagina in een iframe staat
(bijvoorbeeld Google Sites).

Alle inhoud is een indicatie of scenario, stand oktober 2026. Geen advies.
